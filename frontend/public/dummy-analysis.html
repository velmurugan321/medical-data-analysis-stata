Dataset → Dummy Table → Results

Upload datasets and the expected-result dummy table. The backend maps variables, calculates outcome frequencies, p values, crude RR and optional adjusted RR, then returns the original Excel structure filled with results.

01 · Dataset(s)Upload CSV, Excel, Stata or TSV files. Multiple sites/arms are supported.
02 · Dummy tableUpload the expected-result Excel template.
03 · Calculate & fillCounts → p value → crude RR/95% CI → optional adjusted RR/95% CI.
Leave blank only if the system can detect it from the dataset/template. For a binary outcome, also enter the positive value below.
Comma-separated values treated as outcome = 1. Example: 1 or Yes.
Important: leave blank to generate crude RR only. Enter your prespecified confounders/covariates to calculate adjusted RR using Poisson regression with robust variance. The tool will not invent an adjustment model.
