# Medical Data Analysis Checklist

## 1. Data Preparation

- [ ] Dataset imported
- [ ] Number of observations checked
- [ ] Variable names checked
- [ ] Variable labels checked
- [ ] Duplicate records checked
- [ ] Missing values assessed
- [ ] Invalid values checked
- [ ] Outliers assessed

## 2. Variable Creation

- [ ] Age categories created
- [ ] BMI categories created
- [ ] Other required categories created
- [ ] Reference categories defined
- [ ] New variables checked using frequency tables

## 3. Descriptive Analysis

- [ ] Sample size reported
- [ ] Continuous variables summarized
- [ ] Categorical variables summarized
- [ ] Table 1 prepared

## 4. Association Analysis

- [ ] Chi-square test performed
- [ ] Fisher's exact test considered
- [ ] Continuous variable assumptions checked
- [ ] Appropriate statistical test selected

## 5. Regression Analysis

- [ ] Outcome variable verified
- [ ] Crude Risk Ratios calculated
- [ ] Adjusted Risk Ratios calculated
- [ ] Reference categories verified
- [ ] 95% Confidence Intervals reported
- [ ] P-values reported
- [ ] Model assumptions assessed

## 6. Diagnostic Analysis

- [ ] Reference standard verified
- [ ] Index test verified
- [ ] 2 × 2 table checked
- [ ] Sensitivity calculated
- [ ] Specificity calculated
- [ ] PPV calculated
- [ ] NPV calculated
- [ ] PLR calculated
- [ ] NLR calculated
- [ ] Accuracy calculated
- [ ] 95% Confidence Intervals reported
- [ ] ROC curve generated
- [ ] AUC calculated

## 7. Visualization

- [ ] Appropriate graphs selected
- [ ] Axis labels checked
- [ ] Titles checked
- [ ] Legends checked
- [ ] Publication-quality figures prepared

## 8. Final Quality Check

- [ ] Results independently verified
- [ ] Missing data reported
- [ ] Sample sizes consistent across tables
- [ ] Percentages checked
- [ ] Confidence intervals checked
- [ ] P-values checked
- [ ] Tables and figures cross-checked
- [ ] No patient-identifiable data included
- [ ] Final outputs reviewed

## 9. Reproducibility

- [ ] Analysis scripts saved
- [ ] Variable creation documented
- [ ] Statistical methods documented
- [ ] Reference categories documented
- [ ] Output files organized
- [ ] `run_all.do` updated
