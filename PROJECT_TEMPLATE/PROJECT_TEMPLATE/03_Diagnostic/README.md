# 03_Diagnostic

This folder is for diagnostic accuracy analysis.

## Suggested analyses

- 2 × 2 table
- Sensitivity
- Specificity
- Positive Predictive Value (PPV)
- Negative Predictive Value (NPV)
- Positive Likelihood Ratio (PLR)
- Negative Likelihood Ratio (NLR)
- Accuracy
- 95% Confidence Intervals

Clearly define the reference standard before analysis.
