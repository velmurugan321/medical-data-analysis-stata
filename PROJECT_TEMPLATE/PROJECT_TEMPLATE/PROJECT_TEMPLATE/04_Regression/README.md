# 04_Regression

This folder is for regression analysis.

## Suggested analyses

- Crude Risk Ratio (cRR)
- Adjusted Risk Ratio (aRR)
- 95% Confidence Interval
- P-value
- Poisson regression with robust variance
- Confounding assessment
- Reference category definition

## Quality Check

Before regression:

- Verify outcome coding
- Verify exposure coding
- Define reference categories
- Check missing values
- Check sample size

## Reporting

Report:

- cRR
- aRR
- 95% CI
- P-value
