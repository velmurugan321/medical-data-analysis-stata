# 05_ROC

This folder is for ROC curve and AUC analysis.

## Suggested analyses

- ROC curve
- Area Under the Curve (AUC)
- 95% Confidence Interval
- Comparison of diagnostic tests
- Optimal cut-off assessment

## Quality Check

Verify:

- Reference standard
- Test variable
- Direction of the test
- Missing values
- Number of observations

## Reporting

Report:

- AUC
- 95% CI
- ROC curve
- Cut-off, if applicable
