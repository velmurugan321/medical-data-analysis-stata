# TB Lymphadenitis Analysis

## Study Area

Tuberculous lymphadenitis clinical and diagnostic data analysis.

## Main Analysis

The analysis may include:

- Descriptive analysis
- Clinical characteristics
- Demographic characteristics
- Diagnostic test performance
- Sensitivity
- Specificity
- Positive Predictive Value
- Negative Predictive Value
- Positive Likelihood Ratio
- Negative Likelihood Ratio
- Accuracy
- ROC curve
- Area Under the Curve
- Risk factor analysis

## Reference Standard

The reference standard should be clearly defined before analysis.

Example:

- Culture
- Histopathology
- Composite reference standard

The final reference standard must follow the study protocol.

## Diagnostic Tests

Potential index tests may include:

- FNAC
- FNAC smear
- Biopsy smear
- Molecular tests
- Other laboratory tests

The actual variables must be verified from the dataset before analysis.

## Statistical Software

Stata

## Data Privacy

Patient-level data must not be uploaded to this public GitHub repository.

The original dataset should remain in secure institutional storage.
