# Medical Data Analysis Mobile App

V1 foundation for a cross-platform medical data analysis app built with Expo / React Native.

## V1
- Dashboard
- Data upload UI
- Variable View placeholder
- Descriptive Analysis placeholder
- Diagnostic Analysis placeholder
- Regression placeholder
- Reports placeholder

## Run locally

```bash
cd mobile-app
npm install
npx expo start
```

Scan the QR code with Expo Go, or run an Android/iOS simulator.
